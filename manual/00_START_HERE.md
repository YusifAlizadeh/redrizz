# manual/ — шпаргалки на случай «всё сломалось»

Это ручные команды. Если скрипты redrizz не заработали (нет Python-зависимостей,
упала ферма, странный формат сдачи) — открываешь нужный файл и делаешь руками.
Всё рассчитано на копипаст прямо в терминал.

## Порядок боя (если по-простому)

1. **Рекон** — `01_recon.md`. Узнать IP команд, порты, какие сервисы крутятся.
2. **Сдача флага руками** — `02_flag_submit.md`. Проверить, что ты вообще умеешь
   сдать хотя бы один флаг (это главное).
3. **Найти баг** — `03_web.md` / `04_pwn.md` / `05_crypto.md` по типу сервиса.
4. **Фарм руками** — `06_manual_farm.md`. Прогнать рабочую команду по всем командам
   циклом в bash, если ферма не поднялась.
5. **Красть чужое** — `07_steal_traffic.md`. Ловить и повторять чужие атаки руками.
6. **Защита** — `08_defense.md`. Пропатчить, закрыть, не потерять SLA.
7. **Выживание на Linux** — `09_linux_survival.md`. Если дали шелл / надо разобраться.

## Два золотых правила

- **Сначала научись сдавать флаг руками** (файл 02). Пока не умеешь сдавать — эксплойты
  бесполезны.
- **Укради, если не можешь написать** (файл 07). Повторить чужую атаку проще, чем найти баг.

## Сокращения
- `TEAM` — IP команды-соперника (напр. `10.60.3.1`).
- `PORT` — порт сервиса.
- `TOKEN` — ваш токен команды.
